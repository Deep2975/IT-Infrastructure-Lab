# Active Directory Lab

Practical notes and examples for managing users, groups and organisational units in an Active Directory environment.

## Topics

- Active Directory Domain Services
- User and group management
- Organisational Units (OU)
- Group Policy Objects (GPO)
- User permissions
- PowerShell administration

## Scripts

- Export-ADUsers.ps1 – Exports selected Active Directory user information into a CSV report.

## Lab Structure

```text
lab.example

├── Servers
└── Users

    ├── Warehouse

```

All examples are intended for a test environment.
